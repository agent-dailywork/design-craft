# 通用印刷與 PDF

在製作海報、傳單、摺頁、履歷、報告或其他 PDF 交付前讀取。不假設特定平台的匯出器、分頁規則或檔案容量上限。

## 固定頁或流動文件

| 形式 | 適用 | 做法 |
|---|---|---|
| 固定頁 | 海報、傳單、證書、固定頁數簡介 | 每頁明確實體尺寸；檢查裁切邊界與頁序 |
| 流動文件 | 報告、備忘錄、信件、長文 | 自然流動內容，交給實際支援的分頁引擎 |

需求不明時，依受眾與用途選合理預設並說明；台灣與公制情境通常從 A4 開始。已有比例但無實體尺寸的社群圖，保留數位比例，不擅自指定印刷規格。

## 尺寸、解析度與單位

| 紙張 | mm | 約當 CSS px（96px/in） |
|---|---|---|
| A5 | 148×210 | 559×794 |
| A4 | 210×297 | 794×1123 |
| A3 | 297×420 | 1123×1587 |
| Letter | 215.9×279.4 | 816×1056 |

橫式交換寬高。`1in = 25.4mm = 96 CSS px = 72pt`；`12pt = 16 CSS px`。實際 PDF 尺寸以 mm／in／pt 為準，不用四捨五入的 CSS px 反推裁切尺寸。

CSS px 與輸出圖片像素不同：印刷圖片像素 = 英吋 × 目標 ppi。以 300ppi 計算，A4 約需 2480×3508 像素；實際解析度依印刷廠與觀看距離確認。向量形狀保持向量，內嵌照片另查有效解析度。

## 安全邊與出血

- 數位固定稿可從至少 40 CSS px 的內容安全邊起調，連續文字可從 72px 起調；小尺寸與印刷品仍以實際需求為準。
- 印刷出血、裁切、安全邊與裁切標記依廠商規格。常見 3mm 出血只能當待確認值，不能宣稱任何印刷廠都適用。
- 出血是背景延伸到裁切線之外，與內容往內縮的安全邊不同。確認 PDF 的成品尺寸與含出血尺寸。
- 摺頁需確認摺法、外側／內側方向及內摺頁是否要縮窄，不把所有三折都當成等寬三欄。

## HTML 列印

使用標準列印 CSS 作起點，但依實際渲染器測試。以下為無額外出血的 A4 文件示例：

```css
@page { size: A4; margin: 18mm; }
@media print {
  html, body { margin: 0; }
  body { font-size: 12pt; line-height: 1.55; }
  h1, h2, h3 { break-after: avoid; }
  figure, .keep-together { break-inside: avoid; }
  thead { display: table-header-group; }
  .new-page { break-before: page; }
}
```

`@page`、強制分頁、`break-inside`、表頭重複與頁碼支援因引擎而異；不能未驗證就宣稱生效或一律無效。固定頁可使用指定 mm 寬高的頁容器，注意頁邊不要同時在 `@page` 與容器重複加入。

匯出時確認縮放、背景列印、瀏覽器預設頁首頁尾與頁面範圍。沒有分頁控制時，改用可驗證的固定頁或另一個現有匯出工具。

## 內容與紙上閱讀

報告以一個主標開頭，建立 h2/h3 階層。內文原則上至少 12pt、行高約 1.5–1.65；長度以實際語言與字體調整，不把英文每行字元數直接套在中文。

避免孤立標題、跨頁圖說、切斷照片及難以理解的跨頁表格。長文優先單欄；多欄需確認實際閱讀與分頁順序。圖表、表格與程式碼用簡短說明。

傳單以一句短主標統領，時間、地點、費用與行動方式集中呈現。遠看先讀主訊息，近看再讀細節；不要用大量小字補救資訊過多。

線條原則上至少約 0.75pt，文字依紙色保持足夠明度差；轉灰階仍可辨識。大面積深底會增加墨量與閱讀負擔，依用途決定。

## 交付前檢查

1. 實際渲染所有頁面，檢查尺寸、頁數、順序、分頁、裁切與空白頁。
2. 檢查字型嵌入與中文字形、照片解析度、線條與 QR／網址可讀性。
3. 依印刷需求確認 RGB／CMYK、ICC、特別色、出血與 PDF 標準。普通瀏覽器 PDF 不自動等於印刷用 CMYK 或 PDF/X。
4. 附上可編輯來源與已驗證的匯出檔；無法驗證的印刷條件明確列出，不稱為已通過印前檢查。
