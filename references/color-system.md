# 通用色彩系統

在缺少既定配色或需要檢查色彩角色時讀取。不附帶任何公司的品牌色；使用者提供的品牌規範與現有 Token 優先。

## 先定角色，再定色碼

| 角色 | 用途 | 檢查 |
|---|---|---|
| background | 頁面或畫板底色 | 符合品牌語氣與觀看環境 |
| surface | 卡片、面板、浮層 | 與底色可分辨，避免只靠陰影 |
| text | 主文與標題 | 一般文字對比至少 4.5:1 |
| text-muted | 次要資訊 | 小字仍需至少 4.5:1 |
| border | 分隔與控制元件邊界 | 必要的非文字辨識通常需 3:1 |
| accent / on-accent | 主行動及其文字 | 以實際前景與背景配對計算 |
| success / warning / danger | 狀態 | 加上圖示、文字或形狀，不能只靠顏色 |

從一個底色與 0–2 個強調色開始；狀態色另依功能加入。強調色不需平均出現，讓一個角色主導。純白、暖白、冷白、深色均可，依案情決定，不設定跨案固定底色。

## Token 範例

下列僅示範角色命名與引用方式，不是預設品牌或正式配色：

```css
:root {
  --color-background: #ffffff;
  --color-surface: #f1f5f9;
  --color-text: #0f172a;
  --color-text-muted: #475569;
  --color-border: #64748b;
  --color-accent: #1d4ed8;
  --color-on-accent: #ffffff;
}
.action {
  color: var(--color-on-accent);
  background: var(--color-accent);
}
```

若已有 Token，沿用其名稱與數值；不要為了套本範例重命名整個專案。需要新色時，先從既有色的明度、彩度衍生；用 OKLCH 調整時，確認目標瀏覽器與匯出器支援，必要時附上 sRGB 色值。

## 對比與狀態

1. 以實際疊色結果計算，不只比較原始 hex；半透明、背景圖片、漸層都要看文字背後最差的區域。
2. 一般文字至少 4.5:1；大字至少 3:1（約 24 CSS px，或約 18.7px 粗體）。互動元件邊界與必要圖形也要能辨識。
3. 檢查預設、懸停、焦點、選取、錯誤；焦點不能只靠微小色差。
4. 不以「這個灰色通常安全」取代配對檢查。淺底與深底的 muted 色要分別選擇。
5. 色盲與灰階檢查時保留辨識：圖表加標籤、不同線型或形狀；狀態加短文字。

印刷時另外做灰階與實際紙色檢查；螢幕 RGB 對比不等同印刷效果。色彩模式、特別色與打樣見 [print.md](print.md)。
