# 通用字體與排版

在選字體、調整階層、處理中文或排查載入與溢出時讀取。不依賴專有字型，也不假設環境已安裝任何字體。

## 選擇順序

1. 先讀使用者的品牌、設計系統與現有檔案，保留其字體、字重與字級。
2. 沒有指定時，依受眾、內容語言與視覺方向選 1–3 個家族。先確認授權、可取得的檔案與交付環境。
3. 字型缺失時用度量接近的備援，並說明替換；不要只把專有字型名稱寫在 CSS 就宣稱品牌字型已套用。
4. 字型下載或外部網路不可用時，改用可用系統字型或經授權的本地字型。需要完全離線時一併提供允許散布的字型資產。

## 跨環境字型堆疊範例

依實際選定字體修改，以下名稱不代表已載入：

```css
:root {
  --font-sans: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", system-ui, sans-serif;
  --font-serif: "Noto Serif TC", "Songti TC", "PMingLiU", Georgia, serif;
  --font-mono: "SFMono-Regular", Consolas, "Liberation Mono", monospace;
}
body { font-family: var(--font-sans); }
```

拉丁字體可依調性另選；不要強迫中文跟著不含中文字形的標題字體。若混合語系，檢查標點、數字、英文字母與中文基線。直排使用 `writing-mode: vertical-rl` 時，逐字檢查方向與標點位置。

## 階層起點

此表是一般介面與閱讀頁面的起點，海報與特定品牌另依觀看距離調整。

| 角色 | 字級 | 字重 | 行高 |
|---|---|---|---|
| 主視覺標題 | 40–64px | 500–700 | 1.1–1.25 |
| 頁面標題 | 28–40px | 500–700 | 1.2–1.35 |
| 區塊標題 | 20–28px | 500–600 | 1.3–1.4 |
| 內文 | 16–18px | 400 | 1.5–1.7 |
| 標籤／輔助資訊 | 13–14px | 400–600 | 1.4–1.5 |

用比例、留白與位置建立階層，不依賴極粗字重。不要對未提供粗體的字型強制造假粗體。字距依文字系統調整，中文長文不要任意拉大；英文全大寫短標籤可少量加 tracking。

## 載入與驗收

- HTML 使用標準 `<link rel="stylesheet">` 或 `@font-face`，路徑與網域依環境實際支援。沒有唯一指定的字型服務。
- 支援瀏覽器腳本時，可先等待 `document.fonts.ready`；另以 `document.fonts.check()`、載入紀錄與實際字形確認，不把等待完成等同每個字型都成功。
- CJK 檢查實際中文字形，不只測拉丁字母；繁簡字形、標點和缺字方框都可能出問題。
- 在目標尺寸檢查行數、換行、孤行與單行標題。備援字寬不同時，重調版面再截圖。
- 匯出 PDF 後檢查字型嵌入、可搜尋文字與頁面換行；轉外框僅在交付有需要且允許時使用，保留可編輯原稿。
